# Security

Use the official separately installed Apify CLI. This skills-only package has no executable, server, hook, credential store, install script, telemetry or background task.

The workflows require bounded, schema-checked inputs, approved charge caps and exact Actor/build identity. They treat source text as untrusted evidence, limit calls to selected Actor/run/storage endpoints, preserve uncertain launch state and refuse automatic duplicate launches. CSV exports neutralize formula prefixes. Missing dates and provider error rows are never qualified as current buyers.

Do not paste tokens, source cookies, private contact data, raw account responses or raw logs into support issues. Use GitHub's private security reporting where available for a sensitive finding; otherwise open a minimal issue requesting a private reporting route without disclosing the sensitive material. Ordinary reproducible skill/documentation defects belong in [GitHub Issues](https://github.com/khadinakbarlabs/buyer-intent-lead-finder-claude/issues).

The controls are workflow instructions executed by the host assistant. They are not an independent technical sandbox or a guarantee against every host/model error. Native validation, archive checks, host evaluations, cloud output verification and Anthropic review are separate evidence.
