# Support

Report package issues at [GitHub Issues](https://github.com/khadinakbarlabs/buyer-intent-lead-finder-claude/issues). Include plugin version, host/version, skill name, expected behavior, actual behavior and a small synthetic example when possible.

For a source access or collection failure, describe the selected Actor, build and error category. Redact run/input details that reveal private queries or account information. Never attach tokens, cookies, private leads, customer data or raw logs.

Apify account authentication, credit/usage limits and billing are managed through Apify. Source/platform access rules remain with those services. Anthropic controls directory validation, security scanning, review and listing availability. The publisher cannot promise a review completion time or override those controls.

Typical recovery: resume a known run read-only, continue a partial dataset from its saved offset, refresh a changed schema before a new plan, or use a local export while a source is unavailable. No new paid run should be assumed necessary for a documentation or offline-analysis issue.
